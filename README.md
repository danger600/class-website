# Class Website

ReactJS + Vite class website for the SWDFA501 practical assessment.

## Features
- Home, About, Students, and Contact views
- Functional components and reusable components
- Props for school and class information
- Student records rendered with `map()`
- Event handling with `onClick`
- Click counter using `useState`
- No CSS or styling frameworks

## Run locally
```bash
npm install
npm run dev
```

## Check production build
```bash
npm run build
```

## Deployment
Push this project to a public GitHub repository named `class-website`, then import it into Vercel. Vercel should detect Vite automatically.
